# Нужна биография — Серик Айбагаров

**Это единственное, что сейчас блокирует переподачу статьи в IEEE Access.**

Рукопись Access-2026-42535 вернули в статус draft 2 сентября с одним замечанием:
журнал требует биографию **каждого** автора. Пять из шести у нас уже есть —
Мұханбет, Дарибаев и Триго взяты из биографий, которые они написали для своей
статьи в IEEE Access, Шинасылов — из присланного CV, Сапаргали — свою прислал
сам. Не хватает только вашей.

## Заполните, пожалуйста, эти шесть строк

| # | Вопрос | Ваш ответ |
|---|---|---|
| 1 | Высшая учёная степень (PhD, кандидат наук, MSc, BSc) | |
| 2 | По какой специальности | |
| 3 | В каком университете получена (полное название, город, страна) | |
| 4 | В каком году | |
| 5 | Текущая должность и место работы | |
| 6 | Научные интересы — 3–4 темы | |
| 7 | *(по желанию)* предыдущие должности, число публикаций, награды | |

Если степеней несколько (бакалавр / магистр / PhD) — перечислите все с годами и
университетами, так принято в IEEE.

## Почему это спрашивают, а не пишут за вас

Биография публикуется вместе со статьёй. Ошибка в степени, годе или названии
университета исправляется потом только через corrigendum — отдельную
публикацию-опровержение. Поэтому ничего здесь не додумывается.

## Пример — как это будет выглядеть

Из ответов соберётся текст на ~100–150 слов в третьем лице, в формате IEEE.
Готовая биография Дарибаева для сравнения:

> **BEIMBET DARIBAYEV** received the B.S., M.S., and Ph.D. degrees in computer
> science from Al-Farabi Kazakh National University, Almaty, Kazakhstan, in 2009,
> 2011, and 2014, respectively. He is currently the Vice-Rector for Academic
> Affairs and a Member of the Management Board of Shakarim University, Semey,
> Kazakhstan. His research interests include high-performance computing,
> numerical modeling, machine learning, quantum computing, and
> quantum–classical algorithms.

## Фотография — пока не нужна

Редакция запросила только биографии. Портреты для IEEE Access желательны, но в
замечании их не было, поэтому подаём без них.

Если всё же захотите приложить: JPEG или TIFF, **не ниже 300 dpi**, поясной
портрет, вертикальная ориентация, однотонный фон. Портреты из присланного
шаблона не подойдут — Word пережал их до 102–216 dpi, нужны оригиналы.
